The Aria firmware images (FLASHDSK.IMG, ARIAA4.1-3 and the update archives
that contain them) are third-party firmware by Robotron and its licensors,
including Datalight (ROM-DOS), PKWARE (PKLITE) and Borland runtime code.
They are data consumed by the emulator and are not covered by LICENSE.txt.
Do not redistribute them unless you have the necessary rights.

Embedding the firmware in the executable does not change this: compiling it
into the binary is still distribution of the firmware, only less visible. The
images stay separate files that the user supplies from their own machine;
set ARIAFW to the directory that holds them.

The same applies to the Aria technical material (Aria API Reference,
PeterTalk specifications, headers, demo sources and the PC build of
AAPI.EXE). It lives outside the tree; set ARIATECH to point at it. Findings
taken from it are written up in our own words in hardware-map.md and
HANDOFF.md.

The Aria boot ROM is not available at all. The emulator replaces it with its
own high-level emulation, which is original code of this project.
