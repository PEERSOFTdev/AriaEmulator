The files i86inline.h, i86.cpp and i186.cpp in this folder contain code taken
from MAME (https://github.com/mamedev/mame, commit
2aa75c509dca2bebd8cbb3c0e27b9e75d3dcb597, src/devices/cpu/i86/), and i86.h
declares it. The instruction code is kept verbatim; changes for this project
are marked with "ARIA:" comments. That code is under the BSD 3-Clause licence
