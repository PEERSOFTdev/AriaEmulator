MAME (https://github.com/mamedev/mame, commit
2aa75c509dca2bebd8cbb3c0e27b9e75d3dcb597, src/devices/cpu/adsp2100/), and
adsp2100.h declares it. The code is kept verbatim; changes for this project
are marked with "ARIA:" comments, and parts that belong to the MAME framework
